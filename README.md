A program that writes one original fortune line for a houseplant to /output/entry.txt: "The sunbeam that visits at four o'clock has chosen you. It will return every day, faithful as a dog." One line, 100 characters, for make.fun's Fortune in a Pot bounty, where a judge model playing a gardener of thirty years compares entries two at a time on houseplant fortune fit, a small joke that lands, warmth, and the cadence of a prediction — written for this plant, in this window.

## Run it

```sh
node main.ts
```
